############################################################
DATAFRAME
############################################################

Co to jest?

Tabela podobna do Excela.

Przykład:

| store | type | weekly_sales |
|--------|--------|--------|
| 1 | A | 1000 |
| 2 | B | 2000 |

df = pd.DataFrame(...)

############################################################
FILTROWANIE
############################################################

Składnia:

Przykład:

sales[sales["type"] == "A"]

Czytanie:

Zostaw tylko rekordy
gdzie type jest A.

------------------------------------------------------------

Większe od:

sales[sales["weekly_sales"] > 1000]

------------------------------------------------------------

Mniejsze od:

sales[sales["weekly_sales"] < 1000]

VALUE_COUNTS
############################################################

normalize=True

stanowi dana wartość.

############################################################

############################################################
GROUPBY
############################################################

Składnia:

df.groupby("col")

Przykład:

sales.groupby("type")

Co zwraca?

GroupBy object

Jeszcze nic nie liczy.

Tworzy grupy.

############################################################
GROUPBY + SUM
############################################################

Składnia:

df.groupby("type")["weekly_sales"].sum()

Znaczenie:

Podziel dane na grupy typu.

Policz sumę w każdej grupie.

############################################################
GROUPBY + MEAN
############################################################

df.groupby("type")["weekly_sales"].mean()

Znaczenie:

Średnia dla każdej grupy.

############################################################
GROUPBY PO DWÓCH KOLUMNACH
############################################################

Jedna kolumna:

groupby("type")

Wiele kolumn:

groupby(["type", "is_holiday"])

Reguła:

Jedna rzecz -> string

Wiele rzeczy -> lista

Powstają grupy:

A False
A True
B False
B True

############################################################
AGG
############################################################

Składnia:

df.groupby("type")["weekly_sales"].agg(
    ["min", "max", "mean", "median"]
)

Co robi?

Liczy wiele statystyk naraz.

------------------------------------------------------------

Dla wielu kolumn:

sales.groupby("type")[
    ["unemployment",
     "fuel_price_usd_per_l"]
].agg(
    ["min","max","mean","median"]
)

############################################################
UDZIAŁY PROCENTOWE GRUP
############################################################

sales_by_type =
sales.groupby("type")["weekly_sales"].sum()

sales_by_type / sales_by_type.sum()

Pandas zrobi:

A / całość

B / całość

C / całość

automatycznie.

############################################################
PIVOT TABLE
############################################################

Najważniejsza składnia:

df.pivot_table(
    values="kolumna",
    index="grupa",
    aggfunc="mean"
)

------------------------------------------------------------

values

Co analizuję?

Przykład:

weekly_sales

------------------------------------------------------------

index

Po czym grupuję?

Przykład:

type

------------------------------------------------------------

columns

Drugi wymiar grupowania

Przykład:

is_holiday

------------------------------------------------------------

aggfunc

Jak liczyć?

mean
sum
min
max
median

############################################################
PIVOT TABLE PRZYKŁAD
############################################################

sales.pivot_table(
    values="weekly_sales",
    index="type",
    aggfunc="mean"
)

Czytanie:

Pokaż średnią sprzedaż
dla każdego typu sklepu.

############################################################
PIVOT TABLE DWA WYMIARY
############################################################

sales.pivot_table(
    values="weekly_sales",
    index="type",
    columns="is_holiday",
    aggfunc="mean"
)

Czytanie:

Pokaż średnią sprzedaż

dla każdego typu sklepu

oraz osobno

dla holiday=True i holiday=False.

############################################################
GROUPBY VS PIVOT
############################################################

GROUPBY

dogs.groupby(
    ["color","breed"]
)["weight_kg"].mean()

Wynik:

color breed
Black Lab
Black Poodle

------------------------------------------------------------

PIVOT

dogs.pivot_table(
    values="weight_kg",
    index="color",
    columns="breed"
)

Wynik:

          Lab Poodle
Black
Brown

Ta sama informacja.
Inny sposób prezentacji.
